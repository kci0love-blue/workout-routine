# 일주일 운동 루틴 (운동 관리 앱) v0.7

요일별 헬스 루틴 체크, 식단 기록, 하루 100점 평가, 달력 목표 관리를 한 파일로 처리하는 단일 HTML 웹앱입니다. 서버 없이 동작하며 기록은 브라우저(localStorage)에 저장됩니다.

## 주요 기능

- **오늘 운동** — 요일별 루틴 카드를 눌러 실제 수행값(중량·횟수·세트·분)으로 완료 처리. 완료 항목별 소모 칼로리와 하루 집계.
- **부위 순환 루틴 (기본)** — 요일과 무관하게 상체 → 저강도 유산소 → 하체 → 관절보호 유산소 → 전신 → 지방연소 유산소 → 회복 순으로 돕니다. 마지막으로 *완료 기록이 있는 날*의 루틴 다음 것이 오늘 루틴이 되므로 하루 걸러도 순서가 이어지고, 전일(3세트↑) 또는 이틀 합산(6세트↑) 훈련한 부위와 겹치는 루틴은 자동으로 건너뜁니다. 프로필 → 목표 설정에서 요일 고정 방식으로 바꿀 수 있습니다.
- **첫 실행 온보딩** — 처음 열면 "최근에 한 운동" 입력 창이 떠서 어제(또는 마지막 운동일) 한 운동을 체크하면, 그 부위를 피한 루틴으로 오늘부터 시작합니다. 설정 → 데이터 → 「지난 운동 직접 입력」으로 언제든 다시 열 수 있습니다.
- **자동 세부 조정** — 프로필·목표를 저장하면 매일 루틴 수치를 자동 조정합니다.
  - 전날 3세트 이상 훈련한 부위는 48시간 회복을 위해 *선택*으로 낮추고 세트를 1개 줄임
  - 이틀 연속 같은 부위 8세트 이상이면 세트 축소, 전날 총 12세트 이상이면 전체 세트 축소
  - 주간 기록의 통증이 5 이상이면 근력 대신 저강도 회복 루틴(일립티컬·걷기·폼롤링)으로 전환, 통증 부위(3 이상)는 가볍게
  - 점진적 과부하: 직전 기록이 반복 상한을 채웠으면 +2.5kg(레그 프레스 +5kg), 하한 미만이면 −2.5kg
  - 감량 목표는 유산소 30% 증가, 근육 증가 목표는 필수 근력 +1세트·유산소 70%
  - 완료 기록이 시작되면 그날 루틴은 고정(스냅샷)되어 나중에 바뀌지 않음. "기본 루틴으로 보기 / 다시 생성" 버튼 제공
- **식단·평가** — 내장 음식 DB(한식 위주 약 150종)에서 검색해 기록, 사진 첨부(기록용), 끼니별 합계. Claude API 키를 넣으면 사진·설명을 AI가 분석해 자동 입력하고 하루 총평도 작성.
- **하루 점수(100)** — 운동 40 (필수 30 + 선택·마무리 10), 칼로리 30 (허용량 ±10% 만점), 단백질 15, 식단 균형 15 (탄수 40~60%, 지방 20~35%, 정크푸드·술·당음료 감점). 80점↑ 달성 / 60~79 보통 / 미만 미흡.
- **달력·추세** — 날짜별 점수와 색상, 월 달성일·평균 점수·소모 칼로리. 아래에 체중(목표선 포함)·허리둘레·주간 평균 점수·운동별 중량 추세 그래프. 점을 누르면 값이 표시됩니다.
- **휴식 타이머** — 근력 운동 완료 창에 60/90/120초 타이머. 끝나면 진동과 알림음.
- **즐겨찾기·최근 음식** — 식단 탭 검색창 위에 ★ 즐겨찾기와 최근 8개 음식 버튼. 기록 목록의 ☆를 눌러 즐겨찾기 등록.
- **프로필·목표** — 키·몸무게·나이·체지방·골격근·허리둘레·활동량, 목표 유형(감량/유지/증량)·목표 체중·기한·주당 운동일수. BMI·기초대사량·TDEE·목표 칼로리·단백질 목표와 기한 실현성(주당 감량 속도) 분석.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (HTML + CSS + JS + 음식 DB 포함) |
| `img/*.jpg` | 운동 카드 기구 사진 (22장 — `bench.jpg`, `deadlift.jpg`는 임시 그림, 실제 사진으로 교체 가능) |
| `manifest.json` | 홈 화면에 추가 시 앱처럼 열리게 하는 설정 |
| `version.json` | 현재 배포 버전 — 앱의 「업데이트 확인」이 이 파일을 읽어 새 버전 여부를 판단 |
| `.nojekyll` | GitHub Pages가 파일을 가공하지 않도록 하는 표시 |

## GitHub Pages로 배포

1. GitHub에서 새 저장소 생성 (예: `workout-routine`, Public)
2. 이 폴더의 파일을 모두 업로드 (아래 두 방법 중 하나)
3. 저장소 **Settings → Pages → Build and deployment** — Source: `Deploy from a branch`, Branch: `main` / `/ (root)` → Save
4. 1~2분 후 `https://<계정명>.github.io/<저장소명>/` 에서 접속

### 방법 A. 웹 브라우저에서 업로드 (git 설치 불필요)

저장소 페이지 → `Add file` → `Upload files` → 폴더 안 파일 전체를 드래그 → `Commit changes`. `img` 폴더는 폴더째로 드래그하면 구조가 유지됩니다. 숨김 파일(`.nojekyll`, `.gitignore`)은 탐색기에서 "숨긴 항목 표시"를 켜야 보이며, 빠져도 동작에는 지장 없습니다.

### 방법 B. Git 명령어

```bash
cd "C:\Users\e102423\Downloads\운동관리앱_v01"
git init
git add .
git commit -m "운동 관리 앱 v0.2"
git branch -M main
git remote add origin https://github.com/<계정명>/<저장소명>.git
git push -u origin main
```

이후 수정 사항 반영: `git add . && git commit -m "변경 내용" && git push`

## 폰에서 앱처럼 쓰기

배포 주소를 폰 브라우저로 열고 **홈 화면에 추가**(iOS Safari: 공유 → 홈 화면에 추가 / Android Chrome: 메뉴 → 홈 화면에 추가)하면 전체화면 앱처럼 열립니다. 사진 첨부 버튼은 폰에서 카메라를 바로 엽니다.

## 앱 업데이트

설정 탭 → 업데이트 → 「업데이트 확인」. GitHub Pages의 `version.json`과 앱에 내장된 버전을 비교해 새 버전이 있으면 「업데이트하기」 버튼이 나타나고, 누르면 캐시를 비우고 새 파일로 다시 엽니다. 앱을 열 때 6시간에 한 번 조용히 확인하며, 새 버전이 있으면 설정 탭 아이콘에 빨간 점이 표시됩니다. 기록·프로필·API 키는 브라우저에 그대로 남습니다.

새 버전을 배포할 때는 `index.html`과 함께 **`version.json`도 반드시 같이 올려야** 앱이 알아챕니다. (update zip에 항상 포함됩니다)

## AI 분석 (선택)

설정 탭 → AI 분석 → 제공자 선택 → API 키 입력 → 키 저장 → 연결 테스트.

| 제공자 | 비용 | 키 받는 곳 |
|---|---|---|
| **Google Gemini** (기본) | 무료 등급 (카드 등록 불필요, 분당·일일 요청 횟수 제한) | aistudio.google.com → Get API key → Create API key |
| Anthropic Claude | 사용량 과금 (사진 1장 약 5~10원, 선불 크레딧) | platform.claude.com → API keys |

키는 브라우저 localStorage에만 저장되고 해당 API 서버 외에는 전송되지 않습니다. 기본 모델은 Gemini `gemini-3.5-flash-lite`, Claude `claude-sonnet-4-5`이며 모델 칸에서 바꿀 수 있습니다. Gemini 모델이 404(제공 종료·신규 계정 미제공)로 실패하면 계정에서 사용 가능한 Flash 모델을 자동으로 찾아 교체합니다. 무료 한도(429)에 걸리면 1분 뒤 재시도하세요. Gemini 무료 등급은 입력 데이터가 Google 서비스 개선에 사용될 수 있습니다.

> claude.ai 아티팩트 미리보기 환경에서는 외부 API 호출이 차단되므로 AI 기능은 GitHub Pages 또는 로컬 파일에서만 동작합니다.

## 칼로리 계산 기준

- 소모: 유산소 `MET × 체중 × 시간`, 근력은 세트당 (회당 3초 + 휴식 60초)에 부하별 MET 3.5~6, 딥스 보조식은 `체중 − 보조 중량`
- 목표: Mifflin-St Jeor 기초대사량 × 활동계수 = TDEE. 감량 −500 / 유지 ±0 / 증량 +300 (하한 남 1500, 여 1200). 하루 허용량 = 목표 + 운동 소모의 절반
- 단백질 목표: 감량·증량 1.8 g/kg, 유지 1.4 g/kg

어림값이므로 절대치보다는 추세 비교용으로 보세요.
